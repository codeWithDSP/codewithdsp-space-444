# CodeWithDSP Portfolio

A modern static portfolio for Divyanshu Prajapati (DSP), built with HTML, CSS, JavaScript, and a lightweight Three.js space scene.

## Local Preview

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Open:

```text
http://127.0.0.1:8000/
```

## Project Links

Update the live project URLs in `script.js`:

```js
const PROJECT_LINKS = {
  campusflow: "https://campusflow-ai.vercel.app",
  spaceSite: "https://dsp-space-site.vercel.app",
  tradefxbook: "https://tradefxbook-2-0.vercel.app"
};
```

Update LinkedIn and GitHub URLs directly in `index.html`.

## Deploy To Vercel

1. Push this folder to GitHub.
2. Import the GitHub repository in Vercel.
3. Keep the framework preset as static/other.
4. No build command is required.
5. No output directory is required.
